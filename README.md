# 預かったチャンネルの編集を、納品セットにするまで（見本）

架空のクライアント2社の一人語り動画を、案件ごとの設定と辞書で編集に通し、納品前に機械で点検して、
渡すフォルダ（本編・縦型・字幕・点検の結果・納品書）を組んだ見本です。

- 字幕ファイルを貼ると、納品前に見る所を出す点検がブラウザで動きます
- 1本にかかる自分の時間から、月額の下限を出す計算もできます
- 貼った内容・入れた数字はページの外に送っていません（静的ファイルのみ）

見本の音声は macOS の読み上げ音声で、人がカメラの前で話した動画ではありません。
実在のクライアントへの納品記録ではなく、受託の実績・金額の数字はありません。
